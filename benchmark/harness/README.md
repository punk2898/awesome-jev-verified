# The harness

These are the scripts that produced every number in [`../README.md`](../README.md). They are the originals, not a cleaned-up retelling.

## Running it

```bash
npm install ai @ai-sdk/gateway
export AI_GATEWAY_API_KEY=...          # a Vercel AI Gateway key

node fetch_data.mjs                    # pull the public datasets (fixed seed 20260919) into data/
node tasks.mjs                         # build the 2,390 graded questions
node tasks_hard.mjs                    # the harder follow-up set: bigger numbers, mixed date formats, 3-hop, long lists
node run.mjs jev                       # run one model; also: baseline, sol, terra, luna
node special.mjs                       # repeat-consistency, single-call latency, question fan-out
node repeat_llm.mjs                    # same-question repeats for the comparison models
node analyze.mjs                       # accuracy, ECE, Brier, confidently-wrong counts
node stats.mjs                         # paired bootstrap confidence intervals
```

`check.mjs` and `smoke.mjs` are one-call sanity checks; run `smoke.mjs` first to confirm your key works.

## What is and is not included

Results from the 2026-09-19 run are in [`../results/`](../results): one JSONL line per question per model (id, gold label, the probability the model returned, end-to-end and server-side latency, input tokens, cost), plus the aggregate JSON that `analyze.mjs` and `stats.mjs` produce.

The datasets themselves are **not** redistributed here. `fetch_data.mjs` pulls them from the HuggingFace datasets-server with a fixed seed, so running it reproduces the same sample: google/boolq, stanfordnlp/sst2, nyu-mll/glue (RTE), truthfulqa, facebook/xnli, PolyAI/banking77, fancyzhx/ag_news. The synthetic suites — counting, arithmetic, dates, indirection, distractors, injection — are generated by `tasks.mjs` with labels computed in code rather than annotated by hand.

## If you want to argue with the numbers

Good. The places where a reasonable person would push back are listed under "Limits of this test" in [`../README.md`](../README.md) — chiefly that the GPT-5.6 models ran at default reasoning effort, and that their self-reported probabilities make Jev's calibration look better than a log-probability comparison would.
